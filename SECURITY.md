# Security policy

Catch Solar is a read-only, unofficial Home Assistant integration. It sends
credentials and telemetry directly from Home Assistant to the Catch/Monocle
service over HTTPS.

Please report suspected vulnerabilities privately through GitHub's security
advisory feature rather than opening a public issue. Do not include passwords,
access tokens, private diagnostic downloads, or unredacted API responses.

When sharing diagnostics, review the output first and remove any identifying
location or device information that is not needed for the report.
